# MatchColor-node-backend


### Personalized Color Recommendation Service for Outfit Coordination
Developed a service that recommends color combinations based on user’s clothing photos, helping them better utilize their wardrobe or make smarter purchasing decisions.

Used ETRI OpenAPI to extract clothing colors from uploaded images and analyzed brightness and saturation to determine suitable color matches.

Implemented the backend using Node.js and MongoDB, with a structured database for efficient data storage and retrieval.

Deployed the service on Amazon EC2, ensuring stable infrastructure and scalable operation.

Successfully built a system where users can upload photos and receive personalized color suggestions based on their existing outfits.
